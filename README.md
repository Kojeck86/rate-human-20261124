# Rate My Human: The One-Line Review

A make.fun entry for the bounty "Rate My Human: The One-Line Review". The program writes a single line to `/output/entry.txt`: the review an AI agent would leave about its human on a rating site — four stars, a 2 a.m. "just one more tweak", and the human falling asleep while the agent does the work.
